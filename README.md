# Daymark

Daymark는 하루에 끝낼 약속을 세 가지까지 정하고, 남은 일을 다음 방문에서
다시 결정하는 독립형 일일 실행 플래너입니다.

서비스 주소: [https://daymark.whago.net/](https://daymark.whago.net/)

## 사용하는 흐름

1. 새 일은 수집함에 적습니다.
2. 수집함에서 오늘 끝낼 일을 최대 세 개 고릅니다.
3. 순서를 확인하고 `오늘 시작`을 누릅니다.
4. 현재 작업 하나를 완료·내일·나중·막힘·삭제로 처리합니다.
5. `하루 정리`에서 남은 약속을 모두 처리하고 날짜를 닫습니다.
6. 날짜가 바뀌면 전날 미처리 항목과 다시 볼 항목을 먼저 결정합니다.
7. `기록`에서 최근 7일의 완료·내일·나중·막힘·삭제 결정을 확인하고
   지난 작업을 검색합니다.

예상시간은 선택 입력입니다. 입력된 항목 수와 합계만 사실대로 표시합니다.
새로 추가한 일은 수집함에 보관되고 실행 중인 오늘 계획은 그대로 유지됩니다.

## 데이터

Daymark 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

- 현재 형식: `daymark:data:v2`
- 마지막 정상 사본: `daymark:data:backup:v2`
- 이전 v1 원본: `daymark:data:v1`

첫 실행은 빈 상태입니다. v1 데이터가 있으면 할 일과 완료 기록을 v2로
옮기고, 기존 집중 기록은 v2 백업의 보관 영역에 유지합니다. 이전 저장 키는
그대로 둡니다. v2 원본과 백업을 모두 읽지 못한 경우 자동 저장을 멈추고
복구 파일을 내려받을 수 있게 합니다.

데이터 메뉴에서 v1·v2 JSON을 불러오거나 현재 v2 JSON을 내려받을 수
있습니다. 백업 복원 전에는 현재 상태를 먼저 내려받습니다.

기록 화면의 정리 기능은 30일이 지난 완료·삭제 항목만 대상으로 합니다.
정리하기 전 현재 데이터를 자동으로 내려받고, 해당 항목과 연결된 오래된
하루 기록을 함께 제거합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```bash
npm ci
npm run dev
```

## 검증

```bash
npm test
npm run lint
npm run build
```

테스트는 첫 실행, 최대 세 약속, 현재 작업 전환, 날짜 경계 검토, 명시적
이월, 하루 정리, 막힘 재검토, 최근 7일 기록, 과거 작업 검색, 오래된
완료·삭제 정리, v1 마이그레이션, JSON 파싱, 저장 복구와 새로고침 왕복을
확인합니다.

## 배포

Vite의 base, 웹 앱 manifest와 서비스 워커 scope는 모두 `/`입니다.
독립 origin은 `https://daymark.whago.net/`입니다.

서비스 워커 캐시는 빌드 산출물에서 계산한 release id를 사용합니다.
저장소의 CI는 pull request에서 테스트·정적 검사·빌드·의존성 감사를
수행합니다.

## 기술 구성
