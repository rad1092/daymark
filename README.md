# Daymark

Daymark는 하루에 끝낼 약속을 세 가지까지 정하고, 남은 일을 다음 방문에서
다시 결정하는 독립형 일일 실행 플래너입니다.

서비스 주소: [https://daymark.whago.net/](https://daymark.whago.net/)

## 사용하는 흐름

1. 새 일은 수집함에 적습니다.
2. 수집함에서 오늘 끝낼 일을 최대 세 개 고릅니다.
3. 순서를 확인하고 `이 순서로 시작`을 누릅니다. 시작 뒤에는 약속을
   보충하지 않습니다.
4. 현재 작업과 다음 두 작업만 보며 완료·내일·날짜 지정·막힘·삭제로
   처리합니다. 미룰 때는 다시 볼 날짜와 다음 행동을 남깁니다.
5. `하루 정리`에서 남은 약속을 모두 처리하고 결과 기록을 남깁니다.
6. 날짜가 바뀌면 전날 미처리 항목과 다시 볼 항목을 먼저 결정합니다.
7. `기록`에서 최근 7일의 완료·내일·나중·막힘·삭제 결정을 확인하고
   지난 작업을 검색합니다.

예상시간은 선택 입력입니다. 입력된 항목 수와 합계만 사실대로 표시합니다.
새로 추가한 일은 수집함에 보관되고 실행 중인 오늘 계획은 그대로 유지됩니다.

## 데이터

Daymark 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

- 현재 형식: `daymark:data:v3`
- 마지막 정상 사본: `daymark:data:backup:v3`
- 변경 전 복구 지점: `daymark:snapshots:v3`
- 이전 v2 원본: `daymark:data:v2`
- 이전 v1 원본: `daymark:data:v1`

첫 실행은 빈 상태입니다. v1·v2 데이터는 v3로 옮기고 이전 저장 키는
그대로 둡니다. v2에서 날짜가 없던 `나중` 항목은 오늘의 검토 목록에
올립니다. 현재 원본과 백업을 모두 읽지 못한 경우 자동 저장을 멈추고 복구
파일을 내려받을 수 있게 합니다.

데이터 메뉴에서 v1·v2·v3 JSON을 불러오거나 현재 v3 JSON을 내려받을 수
있습니다. 최근 상태 변경은 시간과 함께 복구 지점으로 남고, 다른 탭에서
데이터가 바뀌면 현재 탭의 저장을 멈춥니다.

기록 화면의 정리 기능은 30일이 지난 완료·삭제 항목만 대상으로 합니다.
정리하기 전 현재 데이터를 자동으로 내려받고, 해당 항목과 연결된 오래된
하루 기록을 함께 제거합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```bash
npm ci
npm run dev
```

## 검증

```bash
npm test
npm run lint
npm run build
```

테스트는 최대 세 약속의 교체·순서·고정, 현재 작업 전환, 날짜 경계 검토,
다음 행동이 있는 이월, 하루 결과와 다시 열기, 최근 기록, v1·v2
마이그레이션, 복구 지점, 탭 충돌, 오프라인 자산 목록을 확인합니다.

## 배포

Vite의 base, 웹 앱 manifest와 서비스 워커 scope는 모두 `/`입니다.
독립 origin은 `https://daymark.whago.net/`입니다.

서비스 워커 캐시는 해시된 JavaScript·CSS를 포함하며 빌드 산출물에서
계산한 release id를 사용합니다. iPhone·iPad의 홈 화면 앱은 Safari와
저장 공간이 다르므로 Safari에서 백업한 뒤 설치 앱에서 가져옵니다.
저장소의 CI는 pull request에서 테스트·정적 검사·빌드·의존성 감사를
수행합니다.
