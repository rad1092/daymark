# 네이티브 동작 기준

코드가 컴파일된다는 이유로 운영체제 동작을 지원한다고 표시하지 않습니다.
아래 항목은 대상 OS 실기기에서 통과해야 합니다.

## 데스크톱

- [ ] 실행 중 `Cmd/Ctrl + Shift + D`를 100회 호출해 잘못된 화면에
      나타나거나 포커스를 빼앗지 않음
- [ ] `Cmd/Ctrl + Shift + N`이 다른 앱 사용 중에도 Daymark를 열고 수집
      입력에 포커스
- [ ] 두 번째 실행이 새 프로세스 창을 만들지 않고 기존 창을 표시
- [ ] 창 닫기는 tray로 숨기고 tray의 `종료`만 프로세스를 종료
- [ ] 재부팅 뒤 창 크기와 위치 복원
- [ ] 연결이 끊긴 모니터의 좌표 대신 보이는 화면으로 복귀
- [ ] 항상 위를 끈 상태에서 일반 창처럼 동작
- [ ] 항상 위를 켠 상태에서 일반 창 위에 유지
- [ ] 전체화면 Space·가상 데스크톱 동작을 플랫폼별로 별도 기록
- [ ] 로그인 시 실행을 켜고 끈 결과가 재부팅 뒤 일치
- [ ] 네트워크가 없는 상태에서 수집·계획·완료·재실행 가능

Tauri의 일반 `always_on_top`만으로 macOS 전체화면 Space 동작을
보장하지 않습니다. 전체화면에서도 보여야 한다는 제품 조건을 채우려면
AppKit `NSPanel` 확장과 별도 회귀 시험이 필요합니다.

## 저장과 복구

- [ ] 정상 종료, 강제 종료, OS 재부팅 뒤 마지막 commit 데이터 유지
- [ ] 동시에 저장한 두 창 중 stale revision 저장을 거부
- [ ] 외부 JSON 백업 실패 시 SQLite revision이 증가하지 않음
- [ ] migration 실패 시 기존 DB 파일을 덮어쓰지 않음
- [ ] 마지막 정상 JSON 백업으로 수동 복구 가능
- [ ] 20개 SQLite 백업과 10개 JSON 백업 보존 한도 준수
- [ ] 업데이트 직전 백업 생성

## 업데이트

- [ ] 공개 키가 없는 빌드는 update check를 시도하지 않음
- [ ] 잘못 서명된 artifact 설치 거부
- [ ] 이전 버전에서 새 버전으로 업데이트 뒤 데이터 유지
- [ ] migration 실패 시 새 실행 파일이 원본 DB를 훼손하지 않음

## 모바일

- [ ] iOS와 Android 모두 별도 설치 아이콘과 독립 프로세스로 실행
- [ ] tray·전역 단축키·항상 위·로그인 시 실행 UI가 나타나지 않음
- [ ] background/foreground 전환 중 저장 유실 없음
- [ ] 강제 종료 직전 마지막 완료된 commit까지 복구
- [ ] 공유받은 JSON v1·v2·v3 import
- [ ] 작은 화면과 큰 글자 설정에서 핵심 버튼 접근 가능
- [ ] Android 화면 overlay 권한을 요구하지 않음

위젯, Live Activity, Android quick tile은 현재 출시 범위가 아닙니다. 해당
기능은 실제 iOS·Android 앱의 저장 안정성이 확인된 뒤 별도 설계합니다.
